# Sugumari Kalyana Mandapam — Angular Redesign

A premium, responsive Angular 17 standalone landing page inspired by the information architecture of the existing Sugumari Kalyana Mandapam website, but redesigned with a more modern visual system.

## Run
```bash
npm install
npm start
```
Then open http://localhost:4200

## Build
```bash
npm run build
```

## Included
- Responsive sticky navigation + mobile menu
- Premium hero section
- Venue stats
- Facilities cards
- Wedding/event showcase section
- Filterable gallery + lightbox
- Location/route section
- Enquiry form UI
- Call + WhatsApp CTAs
- Mobile floating call button

## Before production
Replace the demo Unsplash image URLs with the hall's own photos and connect the enquiry form to an email/API/CRM service.
